# Атлас вау

274 места и события на уровне Антарктиды и выше в 16 категориях. Охват — с октября 2026 по декабрь 2027. У каждого места есть фото, интересный факт, даты, цена и риски. Всё собрано на карте мира, в календаре по месяцам и в каталоге с фильтрами.

**Сайт:** https://aksenovyuri2.github.io/atlas-vau/

Шкала вау: **8** — классический круиз на Антарктический полуостров, **10** — Южный или Северный полюс.

## Что внутри

- **Карта.** При наведении на точку появляется фото и краткая справка. Нажатие на точку закрепляет справку, оттуда открывается подробная карточка. Карту можно приближать кнопками «+ / −», двойным кликом или щипком на тачпаде и перетаскивать мышью. Цвет точки показывает уровень вау. Места, где ты уже был, обведены зелёным.
- **Каталог.** Карточки с фото-обложкой: фото можно листать стрелками. В карточке есть интересный факт, сезонная линейка из 15 месяцев, цена и пометки: «виза», «рост», «нужен сертификат», «сверить». Карточки показываются по 48 штук, дальше кнопка «Показать ещё».
- **Подробная карточка.** Галерея из 2–3 фото со ссылками на Wikimedia Commons, факт, все детали, кнопки «Был тут», «В мой список», «На карте» и «Ссылка на место». Между местами можно переходить стрелками ← →. У каждого места свой адрес: `…/atlas-vau/#isl-easter`.
- **Ачивки.** Отметка ✓ «Был тут» на любом месте, общий прогресс «N из 274» и прогресс по категориям.
- **Быстрые подборки:** «Успеть в 2026», «Разовые события», «Вау 9+», «До $1 000», «Рядом с Малагой», «Мой список», «Был тут». Есть кнопка «Случайное место».
- **Фильтры.** Поиск (в том числе по фактам), месяц, бюджет, уровень вау, категории, только проверенные, скрыть посещённые, скрыть закрытые.
- **Календарь.** Гистограмма числа мест по месяцам и список мест по каждому месяцу с миниатюрами.

«Мой список» и отметки «Был тут» хранятся в localStorage браузера.

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | готовый сайт: один файл, шрифты с Google Fonts, фото с Wikimedia |
| `src/data.js` | первая волна мест, с источниками |
| `src/data-more.js` | вторая волна: острова, территории, крайние точки, ачивки (пока «сверить») |
| `src/facts.js` | интересный факт для каждого места |
| `src/photos.js` | 2–3 фото на место (генерируется) |
| `src/template.html` | вёрстка и логика страницы |
| `scripts/wiki-titles.json` | какие статьи Википедии брать для фото каждого места |
| `scripts/photos.mjs` | подбор фото из статей Википедии |
| `scripts/land.mjs` | контуры суши для карты |

## Как редактировать данные

Пример одной записи в `src/data.js` или `src/data-more.js`:

```js
{id:"sea-orcas", c:"sea", t:"Косатки в полярную ночь", loc:"Шервёй, Норвегия", la:70.03, lo:20.97, w:9,
 why:"…", when:"октябрь – январь", m:"10-1", p:"от 3 600 NOK за выход", u:1500, r:0, v:1, f:[],
 n:"…", s:"https://…"}
```

| Поле | Значение |
|---|---|
| `c` | категория: `ant`, `arc`, `fire`, `cave`, `land`, `sea`, `wild`, `sky`, `deep`, `lands`, `isl`, `terr`, `edge`, `rite`, `exp`, `ghost` |
| `la`, `lo` | широта и долгота |
| `w` | вау от 6 до 10 |
| `m` | повторяющийся сезон: `"11-3"` — с ноября по март, `"12-2,6-10"` — несколько окон, `"1-12"` — круглый год |
| `d` | разовые даты в окне: `["2027-08"]` (вместо `m`) |
| `u` | нижняя граница бюджета в USD (используется в фильтре) |
| `r` | риск: 0 — низкий, 1 — средний, 2 — высокий |
| `v` | 1 — подтверждено источниками 2025–2026, 0 — «сверить» |
| `f` | пометки: `visa`, `height`, `cert`, `sold`, `closed`, `exp` |
| `n`, `s` | примечание и ссылка на источник (необязательно) |

Новому месту добавь факт в `src/facts.js` и статьи для фото в `scripts/wiki-titles.json`, затем:

```bash
RETRY=1 node scripts/photos.mjs   # дозагрузит фото только недостающим местам
npm run build                     # соберёт index.html
```

`node scripts/photos.mjs` без `RETRY` подбирает фото для всех мест заново. Для `npm run land` сначала нужен `npm install`.

## Оговорки

Данные собраны 3–4 октября 2026 года. Цены ориентировочные, за человека и без международного перелёта, если не указано иное. Позиции с пометкой «сверить» взяты из общих данных: перед покупкой проверь даты и цены. Рубли пересчитаны примерно по 85 ₽ за доллар.

Фото — Wikimedia Commons через статьи английской Википедии. Авторы и лицензии указаны на страницах файлов, ссылка «Commons ↗» есть в подробной карточке. Контуры суши — Natural Earth 1:110m (public domain) из пакета `world-atlas`.
