# Атлас вау

Около 270 мест и событий на уровне Антарктиды и выше в 16 категориях. Охват — с октября 2026 по декабрь 2027. Есть карта мира, календарь по месяцам и фильтры.

Шкала вау: **8** — классический круиз на Антарктический полуостров, **10** — Южный или Северный полюс.

## Что внутри

- **Карта.** При наведении на точку видна краткая справка: что это, когда ехать, цена и риски. Нажатие на точку закрепляет справку, из неё можно открыть карточку или добавить место в свой список. Карту можно приближать кнопками «+ / −», двойным кликом или щипком на тачпаде и перетаскивать мышью. Цвет точки показывает уровень вау.
- **Быстрые подборки:** «Успеть в 2026», «Разовые события», «Вау 9+», «До $1 000», «Рядом с Малагой», «Мой список».
- **Фильтры:** поиск, месяц, бюджет, уровень вау, категории, только проверенные, скрыть закрытые. Активные фильтры показаны чипами с крестиком.
- **Карточки.** В каждой есть сезонная линейка из 15 месяцев, цена, риски, пометки («виза», «рост», «нужен сертификат», «сверить»), координаты, расстояние от Малаги и ссылка на источник.
- **Календарь.** Гистограмма числа мест по месяцам, на которую можно нажать, и список мест по каждому месяцу.
- **Мой список** (☆) хранится в localStorage браузера.

## Как открыть

Открой `index.html` в браузере. Это один файл без сборщика: шрифты подгружаются с Google Fonts, всё остальное встроено в страницу.

## Как редактировать данные

Места лежат в `src/data.js` (первая волна, с источниками) и `src/data-more.js` (вторая волна: острова, территории, крайние точки, ачивки — пока «сверить»). Пример одной записи:

```js
{id:"sea-orcas", c:"sea", t:"Косатки в полярную ночь", loc:"Шервёй, Норвегия", la:70.03, lo:20.97, w:9,
 why:"…", when:"октябрь – январь", m:"10-1", p:"от 3 600 NOK за выход", u:1500, r:0, v:1, f:[],
 n:"…", s:"https://…"}
```

| Поле | Значение |
|---|---|
| `c` | категория: `ant`, `arc`, `fire`, `cave`, `land`, `sea`, `wild`, `sky`, `deep`, `lands`, `rite`, `exp`, `ghost`, `isl` (далёкие острова), `terr` (территории и анклавы), `edge` (крайние точки и ачивки) |
| `la`, `lo` | широта и долгота |
| `w` | вау от 6 до 10 |
| `m` | повторяющийся сезон: `"11-3"` — с ноября по март, `"12-2,6-10"` — несколько окон, `"1-12"` — круглый год |
| `d` | разовые даты в окне: `["2027-08"]` (вместо `m`) |
| `u` | нижняя граница бюджета в USD (используется в фильтре) |
| `r` | риск: 0 — низкий, 1 — средний, 2 — высокий |
| `v` | 1 — подтверждено источниками 2025–2026, 0 — «сверить» |
| `f` | пометки: `visa`, `height`, `cert`, `sold`, `closed`, `exp` |
| `n`, `s` | примечание и ссылка на источник (необязательно) |

После правки пересобери страницу:

```bash
npm run build      # src/template.html + src/data.js → index.html
```

Контуры суши (`src/land_path.txt`) пересобирать не нужно. Если всё же понадобится, сначала выполни `npm install`, затем `npm run land`.

## Оговорки

Данные собраны 3–4 октября 2026 года. Цены ориентировочные, за человека и без международного перелёта, если не указано иное. Позиции с пометкой «сверить» взяты из общих данных: перед покупкой проверь даты и цены. Рубли пересчитаны примерно по 85 ₽ за доллар.

Контуры суши — Natural Earth 1:110m (public domain) из пакета `world-atlas`.
